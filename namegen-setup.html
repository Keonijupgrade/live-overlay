Name Generator Setup

OBS + phone in about five minutes

1 · Put the files on GitHub Pages

  1. Commit namegen.html, namegen-control.html and this namegen-setup.html to the root of Keonijupgrade/live-overlay.
  2. In the repo: Settings → Pages → Source: Deploy from a branch, branch main, folder / (root). Save.
  3. Wait ~1 minute. Your two URLs are then:
Overlayhttps://keonijupgrade.github.io/live-overlay/namegen.html Phonehttps://keonijupgrade.github.io/live-overlay/namegen-control.html

2 · Add it to OBS

  1. Sources panel → + → Browser → name it "Name Generator".
  2. URL: the overlay URL above.
  3. Width 1080, Height 1920 — matches your vertical canvas exactly, no scaling blur.
  4. Check Shutdown source when not visible OFF (keeps tonight's count alive when you hide the scene) and Refresh browser when scene becomes active OFF.
  5. The overlay background is transparent, so your camera or scene sits behind it.

Tip: put it on its own scene item so you can hide/show it between segments with a hotkey.

3 · Run it from your phone

  1. Open the phone URL on your phone and Add to Home Screen.
  2. Type the name from chat → Run it. The overlay spins and lands the name instantly.
  3. Chat loved it bumps that name up the Hall of Fame.
  4. Clear screen empties the reveal. Reset night wipes the count, ticker and Hall of Fame — do that before you go live.
  5. Green dot on both pages = connected. Red = refresh the page.

It rides the same Supabase realtime channel as your other overlay on a separate namegen event, so it won't collide with your segment control.

4 · Clearing without the phone

  • The overlay has its own Clear and Reset night buttons under the input.
  • Esc in the input clears the screen. Enter runs the name.
  • To hide the typing row entirely for a clean look, keep it phone-only — set the showInput option off.
